- 2026-09-13 · T0.2 · Lint-regel tegen Mongo-writes buiten `apps/server/src/data/` geldt voor de hele repo, ook testbestanden. Tests zetten data klaar via repositories of via helpers in `data/`. · Houdt de audit-garantie ook in testcode zichtbaar.
- 2026-09-13 · T0.3 · Luxon 3, Zod 4. · Huidige stabiele majors.
- 2026-09-13 · T0.3 · Gedeelde schema's beschrijven de **API-vorm**: ids als 24-hex strings, kalenderdatums als dayKey `YYYY-MM-DD`, tijdstippen als ISO-strings. De server vertaalt van/naar BSON (`ObjectId`, `Date` op 00:00 Europe/Amsterdam). · Eén schema voor client én server zonder BSON-afhankelijkheid in de web-bundle.
- 2026-09-13 · T0.3 · `cycle.ts` rekent uitsluitend met dayKeys (kalenderrekenkunde), niet met instants. · Daardoor is cyclus-/weekindex DST-onafhankelijk; conversie naar instant gebeurt alleen in `fromDayKey`.
- 2026-09-13 · T0.4 · Fastify 5, `mongodb` driver 7, `mongodb-memory-server` 11. · Huidige stabiele majors.
- 2026-09-13 · T0.4 · Tests: één Mongo-instantie per testrun (Vitest `globalSetup` + `provide/inject`), elke `createTestApp()` krijgt een eigen database met willekeurige naam die na afloop gedropt wordt. `MONGO_TEST_URL` vervangt de in-memory server. · Snel én geïsoleerd per testbestand.
- 2026-09-13 · T0.4 · Extra config-variabelen: `NODE_ENV`, `APP_FAKE_NOW` (alleen bij `NODE_ENV=test`, zie T5.1) en `WEB_DIST_DIR` (map met gebouwde web-assets voor `@fastify/static`). Foutberichten van config noemen alleen variabelenamen, nooit waarden. · Nodig voor E2E en Docker; voorkomt lekken van secrets.
- 2026-09-13 · T0.4 · Fouten hebben één vorm `{ code, message?, details? }`; validatiefouten zijn 400 `validation_error` met `details: [{ field, message }]`. · Uniform voor de web-client.
